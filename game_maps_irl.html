Installazione Sicura su Android (100% Gratis)

Questa è una Web App (PWA): non devi scaricare file .apk rischiosi né concedere permessi strani. Funziona in sicurezza dentro Chrome su Android usando solo il GPS quando lo attivi.

  1. Salva questo file come index.html in una cartella sul PC o sul telefono.
  2. Carica la cartella gratis su Netlify Drop (app.netlify.com/drop) o GitHub Pages: otterrai un tuo link sicuro https:// (obbligatorio per il GPS Android).
  3. Apri il link con Google Chrome su Android, tocca i 3 puntini in alto a destra e seleziona "Aggiungi a schermata Home" / "Installa app".
Una volta aggiunta alla Home, si aprirà a schermo intero come un'app vera, manterrà lo schermo acceso durante la navigazione e parlerà in italiano per le svolte!
